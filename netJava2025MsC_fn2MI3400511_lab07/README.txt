Решение на домашна работа номер 7;

Проектът съдържа следните папки/файлове:

- `src/` - директория съдържаща изходния код на проекта;
- Client клас - съдържа 'клиент', който иска да се свърже към сървъра;
- Server клас - съдържа 'сървър', който приема клиенти и им предоставя информация

И двата класа имат по един main метод, чрез който може да се тества функционалността на класовете.
