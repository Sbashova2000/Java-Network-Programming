Решение на Домашна работа 2.


Решението представлява Maven проект, който използва JDK25 и се състои от два модула:
- src/main/java - модул, който съдържа основното решение на задачата, т.е FunctionClass.java && Student.java
- src/test/java - модул, който съдържа unit тестове за решението на задачата, т.е FunctionClassTest.java &&  StudentTest.java

Във FunctionClass има main метод, който съдържа примерно извикване на програмата.
